# v0.1 验收清单

1. 登记单图标目录，启动服务，直接 HTTP 读取图标并在软件预览。
2. 删除图标，自动检查后映射变为无效且返回 503；恢复文件后恢复 200。
3. 停用/启用映射；删除映射后资源文件仍然存在。
4. 选择带 CRS 的小型 RGB GeoTIFF，读取元信息，转 0–8 级 XYZ，在 Cesium 预览覆盖区域。
5. 选择非 Byte 单波段 TIFF，启用拉伸后加工，检查 NoData 不呈现为有效影像。
6. 配置真实 CTB Mesh 引擎或 Docker 镜像，将单波段椭球高 DEM 转地形，检查 layer.json、根瓦片和地形起伏。
7. 配置 OSGB 引擎，用包含纹理和多级 LOD 的真实目录验收转换、定位和 Cesium 视角切换。本版本尚无用户 OSGB 样本可验收。
8. 加工途中取消，检查子进程退出且没有误登记半成品；故意选择非空输出目录，已有文件不得改变。
9. 设置内网监听，另一台机器直接使用服务 URL 加载，关闭窗口和退出管理软件后继续访问；明确点击“停止”后发布服务停止。
10. 在目标内网模拟 100 个地图用户的移动和缩放；分别记录冷/热缓存的吞吐、p95 延迟、HTTP 错误、服务器资源和实际浏览器表现。基线不能仅用一个小文件的并发请求代替。

Windows/Linux 的安装、Nginx 进程生命周期、符号链接限制和取消行为须分别测试；当前自动化与应用检查为 macOS ARM64。

- RGB GeoTIFF 生成 XYZ 后通过 Nginx 在 Cesium 显示。

## 独立发布后台验收

- 发布样例资源后关闭主窗口：管理网页服务关闭，GIS 资源仍返回 HTTP 200。
- 关闭窗口期间移除资源：后台监测并将映射变为 HTTP 503；恢复资源后返回 HTTP 200。
- 重新打开软件：复用同一个发布后台进程，正确显示 Nginx 运行状态。
- 独立后台正常退出后 Nginx 持续服务；再次启动后台接管原 Nginx PID。
- 在界面明确停止发布服务，GIS 监听端口关闭。
- 验收脚本仅清理自己的临时后台，不终止用户的发布后台。
