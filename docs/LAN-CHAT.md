# 局域网聊天与直传

桌面侧独立运行聊天服务，退出软件时停止发现、收发和传输；发布后台继续运行不代表聊天用户在线。用户身份保存在本机聊天数据目录，名称取实际局域网 IPv4 地址的最后一段。默认列表显示在线用户，心跳超过 8 秒消失；已打开会话保留离线提示且禁用发送。

使用 UDP 45872 的组播与子网广播发现用户，每 2 秒发送心跳。文件通过局域网 HTTP 动态端口直接传输，不经过外部服务器。防火墙需要允许 GeoPress 在私有网络通信；不同隔离子网不会互相发现。排除常见 VPN、桥接与虚拟网卡。

发送方先发送文件摘要，接收方确认目录后开始拉取。每个分块最多 4 MiB，校验 SHA-256，失败自动重试 3 次；同时最多接收 2 个传输，每个传输并行处理 2 个文件。数据按块写入磁盘，应用不设文件大小上限，也不一次读取整个文件。实际大小取决于文件系统、磁盘空间与操作系统支持。

文件夹保留层级、空目录和空文件，压缩包不自动解压。接收数据先写入隐藏暂存目录，全部完成后提交到以短传输编号区分的接收目录，避免覆盖已有文件。失败后在软件仍运行且发送方在线时，选择同一接收目录可继续已校验的分块；退出或重启软件后需重新发送。符号链接、设备文件与不兼容 Windows 的文件名会明确报错。

聊天记录保存在用户数据目录的 `lan-chat/history.json`。图片在传输完成后提供缩略预览；超过 12 MiB 的图片仍可正常传输，但不生成缩略图。

验证：两个独立实例验证文本、分块文件、目录、空目录、临时网络故障重试、拒绝接收与禁止目录穿越；5 GiB 稀疏文件验证超过 4 GiB 的文件可发起传输，不代表已完整传输了 5 GiB。桌面端验证自动发现、双向聊天、图片预览与压缩包收发。当前验证环境为 macOS，跨 Windows 电脑及实际网线速率仍需目标设备测试。
